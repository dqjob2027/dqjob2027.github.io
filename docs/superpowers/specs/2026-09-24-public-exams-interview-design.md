# 考公考编与面试入口设计

## 目标

在 `https://dqjob2027.github.io/` 的现有三项导航后增加“考公考编”和“面试”两项，保持招聘活动为默认页面，切换栏目时浏览器地址仍停留在网站根网址。

## 页面

- “考公考编”：独立静态页面，按用户提供的顺序列出 6 个腾讯文档的原题和链接。点击链接在新标签页打开，并使用安全的 `rel` 属性。不复制或改写文档内容。
- “面试”：独立静态页面，内嵌用户提供的 45 页《面试100问（完整版）》PDF，并提供“打开或下载 PDF”链接作为浏览器无法内嵌时的备用入口。保留原 PDF 内容和版式。
- 导航沿用现有根页的 iframe 切换方式和视觉风格。手机端让五个按钮保持可点击、可读，不改变已有三个栏目的内容。

## 文件与验证

只修改入口页并新增两个静态页面及一份 PDF。验证导航切换、六个链接、PDF 响应与内嵌、手机宽度和根网址不变化；部署后检查 GitHub Pages 构建状态。
