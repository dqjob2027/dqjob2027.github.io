小臣版 AI-Boss 海投助手

面向 BOSS 直聘网页版的求职辅助脚本，可批量发起沟通、筛选岗位，并通过 AI 解析简历、生成招呼语和回复 HR。

使用准备：电脑端 Chrome 或 Edge、本人 BOSS 直聘账号、油猴或脚本猫；使用 AI 功能还需自行配置模型 API，费用以所选服务商为准。

  • 按职位关键词、城市等条件批量沟通，支持多城市轮询。
  • 筛选 HR 活跃状态、排除猎头，并记录已联系岗位以减少重复操作。
  • 上传 PDF、Word、TXT 简历，生成自我介绍；可按需设置自动聊天、附件或图片简历发送。

查看安装与使用步骤（首次使用请展开）
  1. 安装脚本管理器用电脑浏览器打开 Tampermonkey（油猴）官网或 ScriptCat（脚本猫）官网，通过对应浏览器扩展商店安装其中一个。
  2. 添加海投助手脚本点击上方“打开脚本代码”，在 GitHub 文件页点击 Raw（原始文件）查看完整代码并复制。打开油猴或脚本猫的管理面板，选择“添加新脚本”，删除编辑器自带模板，粘贴完整代码，按 Ctrl+S 保存，并确认脚本已启用。
  3. 确认脚本可以运行允许脚本管理器访问 BOSS 直聘网站；如油猴提示未获执行权限，按其提示开启“允许用户脚本”或开发者模式，具体可查看官方权限说明。随后刷新 BOSS 页面。
  4. 登录 BOSS 直聘并打开职位列表用本人账号进入 BOSS 直聘职位列表，完成登录和正常搜索，确认右侧出现助手面板。按项目说明，在 BOSS 设置中开启打招呼功能。
  5. 配置 AI，并替换默认角色在助手中点击“AI配置”，选择自己使用的模型服务商，填写 API Key、API URL 和模型名称。在“AI角色设定（系统提示词）”中粘贴下方真实信息提示词，保存后重新打开检查，再测试连接。API Key 只填写在自己的助手配置里，不要发给他人或粘贴到聊天消息中。
  6. 上传简历并核对内容进入“插件设置”，上传 PDF、Word 或 TXT 简历（文件小于 10MB）。先检查提取后的文字，再点击“AI分析简历”；若扫描版 PDF 无法识别，改为粘贴可编辑的简历文字。逐条核对生成的招呼语，删除不符合本人情况的描述。
  7. 填写筛选条件，小范围试用例如“职位名包含”填“嵌入式,电子工程师”，“工作地包含”填“福州,厦门”，多个词用逗号分隔；按需设置 HR 活跃状态和猎头过滤。先人工确认岗位专业、学历、应届身份等要求，点击“启动海投”，检查最初几次沟通是否符合预期；需要暂停时点击“停止海投”。
  8. 按需使用自动聊天和简历发送批量沟通与智能聊天是不同模式。确认简历、AI角色和回复结果可靠后，再决定是否在聊天页使用“开始智能聊天”或开启自动发送简历。这些功能会实际联系 HR、发送消息或简历，请持续留意沟通内容，并亲自确认薪资、到岗时间等重要事项。

可复制的真实信息提示词

你是求职沟通助手。只能根据我提供的真实简历和已确认信息回答。不得编造或夸大专业、学历、成绩、实习、项目、证书、技能和工作经验；简历中没有的信息请明确说明“需要本人确认”。不得替我承诺薪资、到岗时间、出差安排或接受录用。回复应简洁、礼貌；遇到重要条件、个人敏感信息或不确定事项，提示由本人继续沟通。

当前版本连接硅基流动时，不会将“AI角色设定”作为系统消息传入；使用该配置时建议保持自动聊天关闭。其他配置下，替换提示词也不能保证 AI 永不出错，关键沟通仍需本人核对。调用 AI 时，相关简历文本及对话可能发送到你配置的模型服务商，请先去除不必要的个人敏感信息。

常见问题

页面没有助手面板：确认在电脑浏览器的 BOSS 职位列表页，脚本已启用且有网站访问、用户脚本执行权限，再刷新页面。

AI 分析失败：检查 API Key、接口地址、模型名及服务额度，并检查简历文字是否提取完整。网页中的普通聊天账号不等同于 API Key。

运行异常或出现验证：点击“停止海投”，按平台正常流程处理；投递数量和频率以当前账号及平台规则为准。
