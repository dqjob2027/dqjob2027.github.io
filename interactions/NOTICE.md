# Interaction sources

Adapted from LeiBox by leishifu666: https://github.com/leishifu666/LeiBox

Components retrieved November 8, 2026 using the official LeiBox Skill CLI,
Vanilla packages, with each original file verified against its SHA-256:

- Fluid Tooltip: navigation selection and moving highlight, adapted for the existing six labelled buttons and CSS transitions. https://leibox.pantoria.cn/docs/animations/fluid-tooltip
- Tactile Push Button: original button surface markup/CSS used for the return-to-top control, recoloured and resized. Community submission by 少荃 (Douyin: 宝龙体育优品小铺); source credit retained in CSS. https://leibox.pantoria.cn/docs/animations/tactile-push-button
- Sailing Toc: scroll-follow selection and chapter navigation adapted for the existing 100 question anchors. The demonstration article, boat illustrations and fonts are not included. https://leibox.pantoria.cn/docs/animations/sailing-toc

Adaptation keeps the website's original content and navigation. No demo images,
logos, embedded fonts or GSAP runtime are included. Full downloaded packages and
checksum manifests remain in the local work/leibox folder for review.
